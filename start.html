How it works in five steps

  1. Open Courses and pick a course. HTML is a good first choice for websites, and Python is an easy first language.
  2. Take a lesson: read the idea, run the example code, then answer the question to complete it.
  3. Practise in the Playground, solve Challenges and try the Command Lab.
  4. Check your Dashboard for completed lessons and your daily streak, and use Review mistakes to fix what you missed.
  5. Go further with Project Lab, Career Studio and Interview Studio.
