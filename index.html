Your first 6 months

A simple order that works for most beginners.

  1. Month 1

    Learn HTML, CSS and basic JavaScript. Build a personal page.

  2. Month 2

    Study JavaScript deeply. Make a to-do app and a weather app.

  3. Month 3

    Learn Git and GitHub. Publish your projects online.

  4. Month 4

    Pick Python or React. Solve easy problems on LeetCode weekly.

  5. Month 5

    Learn SQL and build an app with a database behind it.

  6. Month 6

    Build one bigger project, write about it, and start applying.

Questions

Is Duncan's Tech School free?

Yes. The interactive lessons are free, and the library links to sites that are free to start. A few linked sites also sell paid plans, which are always optional.

Do I need any experience?

No. Start with HTML fundamentals or Python programming, both made for complete beginners.

How do the interactive lessons work?

Read a short lesson, edit the code in the browser, see the result instantly, then answer a quick quiz. Your progress is saved in your browser.

Which course should I take first?

If you want websites, start with HTML, then CSS, then JavaScript. If you prefer general programming, start with Python.

Do I get a certificate?

Yes. Complete every lesson in an interactive course to unlock a downloadable Certificate of Completion. It recognises completion of the course on Duncan’s Tech Schools; it is not an accredited academic qualification. Your projects and practical skills remain important evidence of what you can do.
