LC-3 Fundamentals Practice TestSuggested time: 15 minutes

This is a self-study practice test, not a formal or proctored examination. Your score is saved locally on this device.

Coding practice test

For each task, write and run a complete program in the LC-3 Lab. Use the debugger to verify register and memory results.

Task 1 · Arithmetic

Assume R0 and R1 contain two values. Add them and place the result in R5.

Task 2 · Maximum value

Compare signed values in R0 and R1. Place the greater value in R5. Test equal values and negative values too.

Task 3 · Memory

Load three consecutive values from an array, add them and store the sum in a labelled memory location.

Task 4 · Output

Use .STRINGZ and PUTS to display a greeting, then halt cleanly.

Task 5 · Counting

Write a program that counts from 1 to 10. Leave the final count in R2 and use a loop rather than ten repeated ADD instructions.

Task 6 · Maximum of two values

Read signed inputs from R0 and R1 and store the greater value in R5. Include tests for equal, positive and negative inputs, and explain the signed-overflow limitation of subtraction-based comparison.

Task 7 · Array sum

Given five consecutive values beginning at ARRAY, calculate their sum and store it in TOTAL. Use LDR and a loop.

Task 8 · Character conversion

Assume R0 contains an ASCII digit from '0' to '9'. Convert it to its numeric value and leave the result in R5.

Task 9 · Subroutine

Write a subroutine named DOUBLE that doubles the value in R0 and returns to the caller. Demonstrate it with JSR and RET.

Task 10 · String output

Store a short message with .STRINGZ and display it using LEA and PUTS. Make sure the program halts after output.
