Quick lessons
  1. Registers: R0–R7 are eight 16-bit general-purpose registers.
  2. PC: the program counter stores the address of the next instruction.
  3. Condition codes: N, Z and P record whether the last result was negative, zero or positive.
  4. Memory: LC-3 has 65,536 addressable 16-bit memory locations.
Try these exercises
  • Change the program to print a different digit.
  • Use a loop and BRnzp to count down from 5.
  • Store a value in memory with ST, then load it with LD.
  • Use .STRINGZ and PUTS to print a short message.
The code corrector applies limited, transparent syntax fixes (such as normalising label names) and then checks the program with this lab assembler. It is not a substitute for understanding the code. TRAP x20 (GETC) is not interactive in this browser version.
