HTML, CSS and JavaScript: what each one does

By Duncan · 18 October 2026 · 3 min read

Every website you visit is built from three languages that work together. Think of a house.

HTML is the structure

HTML describes what is on the page: headings, paragraphs, links, images and forms. It is the walls and rooms of the house. Try it in the first HTML lesson.

CSS is the style

CSS controls how things look: colors, spacing, fonts and layout. It is the paint, furniture and decoration. Learn it in CSS selectors and color.

JavaScript is the behaviour

JavaScript makes the page react: menus that open, buttons that count, forms that check your input. It is the electricity and plumbing. Start with variables and output.

How to learn them

Learn them in this order: HTML, then CSS, then JavaScript. After each lesson, change the code and see what happens. Breaking things on purpose is a great way to learn.
