Debugging for beginners: a 6-step routine

By Duncan · 18 October 2026 · 4 min read

Every programmer writes bugs. What separates beginners from confident developers is not fewer bugs, it is a routine for finding them. Here is one you can use today.

The routine

  1. Read the error message. Start at the last line. It usually names the problem and the line number.
  2. Reproduce it. Find the smallest input that breaks your code every time.
  3. Isolate it. Comment out parts until the bug disappears. The last part you removed is the suspect.
  4. Look at the values. Print variables with console.log or print and compare them with what you expected.
  5. Change one thing at a time. If you change five things, you will not know which one fixed it.
  6. Explain it out loud. Describing the code line by line to a friend, or a rubber duck, often reveals the mistake.

Common beginner bugs

  • A typo in a name, or a missing bracket or quote.
  • An off-by-one mistake, such as starting a loop at 1 instead of 0.
  • Using the wrong operator, like > instead of >=.
  • Forgetting to return a value, or returning too early.
