Working with dates

Dates read from a file are often plain text. Convert them so you can sort, filter and group by day, month or year.

Press Run to see the result.

Example
df["date"] = pd.to_datetime(df["date"])
df.groupby(df["date"].dt.month)["sales"].sum()
