DEPLOYMENT
1. Extract the ZIP.
2. Open the `duncans-tech-schools-deploy` folder.
3. Deploy the CONTENTS of that folder to the existing Netlify site (or connect the folder to the existing Git repository).
4. Keep Netlify publish directory as `.` and functions directory as `netlify/functions`.
5. After deployment, open `/dashboard`, test the focus timer, save a weekly target, export a backup, then test restore using that backup.
6. Hard-refresh once so the updated service worker and assets are loaded.
